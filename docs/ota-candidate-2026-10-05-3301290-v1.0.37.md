The token-free OTA test environment built from this clean source commit using
the local production configuration. The packager checked configured private
values, generated only the firmware/checksum pair, and `--verify-only` passed.
The package remains under ignored `.pio/`; no release or public binary was

The retry now calls `SD.end()`, `SPI.end()`, then waits before the next
`SD.begin()`. This matters because the ESP32 Arduino SD implementation only
unmounts in `SD.end()` when card initialization assigned a drive, while
`SPI.begin()` is idempotent when the controller is already active. The host
regression test locks down the cleanup/reset/wait order, and the lifecycle
harness passes. This is a recovery improvement based on source behavior, not
proof of the physical card's root cause.

The general production environments could not be built because this checkout
does not have the required telemetry token available; the OTA test build is
token-free. The device is disconnected. Physical card retry behavior, SD
journalling, USB telemetry, uploads, and OTA acceptance/rollback remain
hardware checks. Do not publish or flash on host evidence alone.
